# FastMCP

Пример удалённого MCP-сервера на [FastMCP](https://gofastmcp.com), который можно развернуть без
настройки. К нему подключаются ИИ-ассистенты с поддержкой MCP: Claude, ChatGPT, Cursor и другие.

## Параметры деплоя

| Поле | Значение |
| --- | --- |
| Сборка | Railpack |
| Путь до директории проекта | `/` |
| Команда установки зависимостей | оставьте пустым |
| Команда сборки | оставьте пустым |
| Команда запуска | оставьте пустым |
| Порт приложения | `8000` |
| Путь проверки состояния | `/health` |

Railpack видит `requirements.txt`: ставит FastMCP и запускает `main.py`. Сервер слушает порт из
переменной окружения `PORT` — её передаёт платформа, — а без неё `8000`.

## Подключение

Адрес сервера — `https://<адрес приложения>/mcp`. Добавьте его в клиенте MCP как удалённый сервер.

Инструменты сервера:

- `add` — сумма двух целых чисел;
- `echo` — возвращает переданный текст;
- `utc_now` — текущие дата и время в UTC.

Авторизации в примере нет: вызвать инструменты может любой, кто знает адрес. Прежде чем добавлять
свои инструменты, включите [авторизацию](https://gofastmcp.com/docs/servers/auth/authentication).

## <a name="dev"></a>Локальный запуск проекта

```bash
# виртуальное окружение и зависимости
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt

# запуск сервера
python3 main.py
```

Адрес сервера — `http://localhost:8000/mcp`, проверка состояния — `http://localhost:8000/health`.
Нужен Python 3.11 или новее.
